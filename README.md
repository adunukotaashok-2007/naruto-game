# 🥷 Shinobi Battle Arena

A fan-made Naruto-inspired browser fighting game.

## Features

- Character selection
- Fighting arena
- Health system
- Chakra system
- Normal attacks
- Jutsu attacks
- Dash
- CPU opponent
- Mobile controls
- Keyboard controls
- GitHub Pages deployment

## Controls

### Keyboard

A = Move Left

D = Move Right

J = Normal Attack

K = Jutsu

Space = Dash

### Mobile

◀ = Move Left

▶ = Move Right

👊 = Attack

🔥 = Jutsu

💨 = Dash

## Characters

- Naruto
- Sasuke
- Kakashi
- Sakura
- Shikamaru
- Gaara
